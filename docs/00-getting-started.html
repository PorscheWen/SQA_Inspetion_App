這是什麼專案？

完整的自動化測試系統，包含：

  1. 被測應用程式 (SUT) — Semi Inspection Desktop（WinForms）：匯入 Recipe、查看參數、缺陷圖表、模擬檢測。
  2. 自動化測試框架 — FlaUI + SpecFlow（Gherkin）+ 10 個 TC（功能與負面）。
  3. 工具鏈 — main_menu.bat、Web 控制台、HTML 報告、互動式操作手冊。

5 步驟快速開始

步驟 1：確認環境

  • Windows 10/11、.NET SDK 8.0+、MSBuild
  • Python 3.x（Web 控制台／手冊伺服器，可選）
dotnet --version python --version

或選單 [13] 環境診斷。

步驟 2：開啟主選單與手冊

Windows：雙擊 main_menu.bat

  • [9] → 本頁（新手入門）
  • [7]（Python）或 [8]（離線）→ 操作手冊
  • Python 伺服器：http://localhost:6688/docs/index.html

Linux / Codespaces：執行 ./open_user_manual.sh；Port 問題見 PORT_FORWARDING_GUIDE.md。

步驟 3：啟動被測應用程式

  • 推薦：選單 [4]
  • 或先 [5]／build_semi.bat，再 [4]
驗證：視窗標題「Semi Inspection Desktop」、左側 File Tree、工具列有 Import Recipe / About。

步驟 4：執行第一個測試

  • A（推薦）：[1] Run all tests — 全跑 TC01–TC10
  • B：[2] Run single test — 輸入例如 TC01
  • C：[3] Start web dashboard — Web 控制台勾選執行

步驟 5：查看測試報告

選單 [6] Open test report。報告路徑：

Automation_testcase/Project_FlaUIBDD/ Testcase_Inspection_App_FlaUI_BDD/reports/ TestResultReport.html ← 主要報告 junit-results.xml media/ ← 失敗截圖

常見問題 (FAQ)

Q1: Linux / Codespaces 能跑測試嗎？

不行。FlaUI 與被測 App 為 Windows 專用。Linux 可改碼；Windows 執行測試；用 Git 同步。

Q2: 如何查 AutomationId？

選單 [15] 或 open_inspector.bat → Hover Mode。逐步圖文見 FlaUI 教學 · FlaUInspect；安裝見 tools/README.md。

Q3: 測試失敗怎麼除錯？

  1. [6] Open test report 看報告與截圖
  2. [4] 手動重現
  3. [15] 確認控制項 ID
  4. 讀 第 4 章

Q4: 如何新增測試案例？

TPS → Feature → Steps（只編排／Assert）→ PageObject → 選單 [2] Run single test。見 第 2 章。

Q5: Web 控制台無法開啟？

確認 python --version；選單 [3] Start web dashboard 或 web_dashboard/open_dashboard.bat；檢查 Port 6690（選單 [13]）。

給新手的建議

建議做

  • 從本頁與操作手冊開始，先手動操作 App 再看自動化
  • 先跑現有測試；閱讀順序 TC02 → TC06 → …
  • 安裝並熟悉 FlaUI Inspector；優先 AutomationId 與快捷鍵
  • 小步迭代：一次改一個 TC 立刻驗證

避免做

  • 在 Linux 跑 FlaUI 測試
  • 在 Step Definitions 直接寫大量 FlaUI（應放 Page Object）
  • 寫死絕對路徑、忽略等待與 null 檢查
  • 跳過 TPS、同時改一堆 TC、忽略失敗原因
